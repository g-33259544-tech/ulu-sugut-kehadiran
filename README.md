# Kehadiran SMK Ulu Sugut (Malinsau)

Demo dengan 36 murid contoh. Tiada data murid sebenar.

Rekod disimpan dalam localStorage pelayar pada alamat laman ini. Tiada pangkalan data pusat, log masuk atau penyelarasan antara guru. Jangan gunakan sebagai rekod rasmi. Eksport CSV untuk salinan rekod.

Buka sekali dengan internet, tunggu fail luar talian tersedia dan muat semula sebelum menguji luar talian. Perkhidmatan service worker memerlukan HTTPS.

GitHub Pages: main, folder root. Tiada proses build diperlukan.
